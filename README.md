# Проект: VacancyDatabase

[![Python Version](https://img.shields.io/badge/python-3.10%2B-blue)](https://www.python.org/)
[![Code Style: Black](https://img.shields.io/badge/code%20style-black-000000.svg)](https://github.com/psf/black)
[![Testing: Pytest](https://img.shields.io/badge/testing-pytest-green)](https://docs.pytest.org/)


В рамках проекта вам возможно получить данные о компаниях и вакансиях с сайта hh.ru, 
спроектировать таблицы в БД PostgreSQL и загрузить полученные данные в созданные таблицы.

## ✨ Основные возможности

- Возможность 1: Загрузка вакансий с hh.ru через API
- Возможность 2: Сохранение списка вакансий в БД и выгрузка из неё
- Возможность 3: Взаимодействие с пользователем

## 🛠 Технологии

- **Python 3.10+** - основной язык программирования
- **Poetry** - управление зависимостями
- **Pytest** - тестирование кода
- **PostgreSQL** - используемая база данных

## 📦 Установка и запуск

### Предварительные требования

- Python 3.10 или новее
- Poetry

### Клонирование и установка

```bash
# Клонирование репозитория
git clone https://github.com/Larnou/VacancyDatabase.git
cd ваш-репозиторий

# Установка зависимостей через Poetry
poetry install

# Активация виртуального окружения
poetry shell
```

## 🚀 Использование


Чтобы понимать, как работают классы и функции в проекте, 
для каждого описан docstring. Ниже можно найти полный список всех реализованных функций, 
разбитых по модулям:

**Классы**

* `HeadHunterAPI` — Класс HeadHunterAPI, обеспечивает связь с HH Api и получение списка 
работадателей и их вакансий.
* `Employer` — Класс Employer, позволяет хранить информацию о работадателе в удобном виде.
* `Vacancy` — Класс Vacancy, позволяет хранить информацию о вакансии в удобном виде.
* `RatesAPI` — Класс RatesAPI, обеспечивает получение информации по курсу валют. 
Необходим для конвертации заработной платы из других валют в рубль.
* `FileManager` — Класс FileManager, позволяет обеспечить сохранение результатов 
запроса из БД в файлы формата название.json.
* `DBManager` — Класс DBManager, позволяет реализовать подключение к базе данных, 
созданием необходимых таблиц, добавление данных и использование SQL-запросов к базе данных PostgreSQL.
